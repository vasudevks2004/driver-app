# HireD Driver — Flutter Android + iOS

**HireD provides drivers, not cars.** Partner companies and customers provide the vehicle. The app manages assigned driver duties (called trips by the Phase 1 backend).

## Getting started

```bash
flutter create . --platforms=android,ios
flutter pub get
flutter run
```

Android requires the Flutter SDK and Android tooling; iOS builds require macOS/Xcode. Native platform directories are generated by `flutter create .` and are not yet committed.

## Included features

- Driver demo dashboard and online/offline availability
- Fourteen-day availability calendar
- Assigned driver duties, start, selfie, expenses and OTP close
- Completed duty history and per-duty wallet credits
- Driving License, Aadhaar Card, PAN and PCC uploads
- Optional authenticated REST API adapter for future backend integration
- HireD branding: indigo `#5055F7`, Inter typography and the official logo asset

### Demo workflow

Launch the app, open assigned duty `TRP-1028`, start, capture a selfie, log expenses (enter `No expenses` and `0` if applicable), then enter demo OTP `4826`. The demo wallet updates in local memory only, and resets when the app restarts.

### Backend mode

```bash
flutter run --dart-define=API_URL=https://YOUR-HOST/api/v1
```

Open Profile and choose login. Contract assumptions are documented in `GITHUB_SETUP.md` and `lib/api.dart`; the deployed modular monolith must validate ownership, trip status, expenses, OTP, and atomically credit the driver wallet exactly once.

### Build

```bash
flutter build apk --release
flutter build ipa --release
```

The second command must run on macOS with Xcode and distribution signing.

## Current limitations

This is a Flutter frontend/demo scaffold, **not a verified production app**. Flutter/iOS/Android builds and device tests have not been run here; backend endpoints are proposed and require reconciliation with the existing HireD backend. Add camera/photo permissions to generated native platform projects before release.

UniT7 remains separate; this repository is the standalone driver mobile app.
